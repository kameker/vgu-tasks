# Глава 11. Упражнения 1, 2, 4, 7 и 8

Запуск из корня проекта — `python task4/lab_transforms.py`. Нужны `opencv-python`, `numpy` и `matplotlib`. Результаты сохраняются в `task4/results`.

**1.** На инвертированном полутоновом изображении рассчитан отклик оператора Лапласа с ядром 9 × 9. Максимумы в областях глаз отмечены красными кружками. Области глаз заданы для присланной фотографии `face.jpg`, поэтому при замене фотографии их координаты нужно изменить.

**2.** Красной точкой отмечен центр преобразования. Для квадрата с центром в вершине получаются кривые от сторон квадрата. Для центра внутри окружности получается непрерывная волнообразная линия. Для центра снаружи получается замкнутая петля, поскольку только некоторые лучи пересекают окружность. На горизонтальной оси результата расположен логарифм расстояния, на вертикальной — угол.

**4.** Четыре квадрата преобразуются относительно общего центра. Изменение размера даёт сдвиг вдоль оси логарифма радиуса, а поворот — вдоль оси угла. Фазовая корреляция находит сдвиг относительно первого квадрата. После совмещения выбранная точка контура переносится к центру изображения. Небольшие различия остаются из-за дискретизации.

**7.** Для четырёх снимков из `task2` показаны исходные полутоновые изображения и результаты `equalizeHist`. Выравнивание перераспределяет яркость и меняет контраст. Результат зависит от исходного распределения яркости.

**8.** Выравнивание гистограммы меняет распределение значений яркости, чтобы усилить контраст. Очистка от шума старается уменьшить случайные колебания яркости или цвета с сохранением деталей. При выравнивании шум может стать заметнее.
